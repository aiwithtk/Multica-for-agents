# Multica for agents

Ressources partagées pour les agents Multica du workspace **Vector Dynamics OS**.

## Contenu

| Chemin | Rôle |
|---|---|
| `carousel-templates/` | Templates de positionnement de texte pour carrousels (`corporate`, `minimal`) |
| `.env.example` | Variables d'environnement pour le pipeline YouTube (reader / writer / responder) |

## Skills

Les skills `persona-cm` (ton de marque — « Le Stratège Opérationnel ») et `memory-context`
(mémoire long terme : prospects, hot topics, black list) sont désormais gérés **directement
dans Multica** en tant que workspace skills. Importés le 2026-09-24, ils ne sont plus
versionnés dans ce dépôt.
